## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### PDF preview setup

PDF preview uses the TeX compilation service. Set `TEX_API_KEY` in `.env.local`, then restart the development server.

### Authentication email setup

Email/password signup verification and password reset use Nodemailer over SMTP. Add these values to `.env.local`, then restart the development server:

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-smtp-user
SMTP_PASS=your-smtp-password
SMTP_FROM="ResumeIQ <no-reply@example.com>"
```

Add `${NEXT_PUBLIC_APP_URL}/api/auth/google/callback` as an authorized redirect URI in Google Cloud Console. Google OAuth accounts are verified by Google automatically. SMTP credentials must be configured for email/password signup and password reset to work.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
